## 현재 구현 상태

| 영역                   | 상태                                                            |
| ---------------------- | --------------------------------------------------------------- |
| 프론트 P0 흐름 | 기존 로컬 UI + Spring 계약에 맞춘 HTTP 어댑터·입력/네트워크 복구 |
| 랜딩                   | Freshman 인트로·큰 서비스 설명·확대 헤드셋·노랑 CTA·4개 소개 구현 |
| 가독성·행동 구분        | 본문 17~18px·큰 버튼·한글 메뉴·노랑/보라 핵심 카드·선명한 선택 상태 |
| 전체 화면 인트로       | 헤더·하단 릴을 제외한 콘텐츠 전체에 적용                        |
| P1 팔로우·공유         | 로컬 UI 구현, 실제 팔로우 API 미연동                            |
| P2 채팅·공동 목록·피드 | 경로·연결 확인·준비 안내만 제공                                 |
| Spring·PostgreSQL | 14개 테이블·V1/V2·30개 API·실제 임시 DB 테스트; HTTP 브라우저 통합은 미검증 |
| JCloud                 | 프록시 예시만 준비, 미배포                                      |
| 검증                   | 프론트 66개·보드 3개·백엔드 72개 검사와 빌드 통과; 운영/브라우저 연동 미검증 |
