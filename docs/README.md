## 현재 구현 상태

| 영역                   | 상태                                                            |
| ---------------------- | --------------------------------------------------------------- |
| 프론트 P0 흐름         | 브라우저 로컬 데이터로 가입·취향·탐색·초대·관심 요청 UI 구현    |
| 랜딩                   | Freshman 스타일의 타이틀 인트로·워드마크 Hero·4개 소개·CTA 구현 |
| 전체 화면 인트로       | 헤더·하단 릴을 제외한 콘텐츠 전체에 적용                        |
| P1 팔로우·공유         | 로컬 UI 구현, 실제 팔로우 API 미연동                            |
| P2 채팅·공동 목록·피드 | 경로·연결 확인·준비 안내만 제공                                 |
| Spring·PostgreSQL      | 폴더·설정·계약 초안, 실행 앱·DB 미구현                          |
| JCloud                 | 프록시 예시만 준비, 미배포                                      |
| 검증                   | 앱 검사 51개·빌드 통과; 실제 브라우저 실측·서버/DB 통합 미검증  |
