# 구현 경계와 구조

## 이번에 구현한 프론트

`frontend/src/app`은 Router와 세션 표시를, `features`는 기능별 화면을 담당합니다. `api/types.ts`의 동일 인터페이스를 브라우저용 `mock.ts`와 향후 Spring용 `http.ts`가 구현합니다. 페이지가 저장소를 직접 다루는 예외는 P1 로컬 팔로우뿐이며 계정별 키로 분리했습니다.

기본 모드에는 가짜 사용자·관심 요청·연결이 없습니다. 직접 가입한 계정과 저장한 취향만 비교합니다. 예시 카탈로그의 제목·아티스트와 CSS 추상 아트는 선택 UI용이며, 실제 음원이나 앨범 이미지를 수집하지 않습니다. 직접 추가한 메타데이터도 같은 카탈로그에 저장됩니다.

취향 완성 기준은 아티스트 5개, 곡 10개, 장르·무드 각각 1개 이상입니다. 각 입력 단계 저장을 허용하며 장르/무드는 각각 최대 3개입니다. 공개 기본값은 false입니다. 문서에 미확정인 숫자는 기존 프론트의 선택 개수를 유지한 현재 UI 정책입니다.

기본 유사도는 아티스트 집합 Jaccard 40% + 곡 30% + 장르·무드 30%입니다. 실제 선택에 근거한 공통점·차이만 표시합니다. AI 호출과 임베딩은 구현하지 않았고 항상 기본 프로필을 사용합니다. 분석 화면의 짧은 전환은 UI 연출이며 서버 AI 작업이 아닙니다.

라우팅은 정적 호스팅에서도 직접 진입할 수 있도록 HashRouter를 선택했습니다. API URL은 hash와 무관하게 `/api/v1`입니다. 네 가지 메뉴는 Home·Discover·Music·My Taste이고, 작은 화면에서는 하단 내비게이션을 제공합니다.

## 백엔드: 구조·설정만

`backend`에는 Java 패키지, 테스트 위치, 리소스/Flyway 위치, Gradle의 Java 21 기본 설정만 있습니다. **Spring Boot 플러그인·의존성·실행 클래스·Controller·Service·Repository·Entity·DB 마이그레이션은 추가하지 않았습니다.** 서버는 아직 실행 가능한 앱이 아닙니다. Spring/JDK 최종 호환 버전은 서버 구현 시 확정합니다.

설정 초안은 PostgreSQL 환경변수, JPA validate, Flyway, 세션 쿠키와 local/prod 구분을 제안합니다. 설정 파일만으로 인증·인가·CSRF·트랜잭션이 구현되지는 않습니다. 향후 Spring에서 이를 강제하고 검증해야 합니다. 설정에 비밀번호나 실제 접속 주소를 넣지 않았습니다.

최종 배포 대상은 Notion대로 JCloud입니다. `deploy/nginx`는 React 정적 파일과 `/api`의 같은 출처 구성을 위한 검토용 예시입니다. VM·HTTPS·DB 배치·systemd/컨테이너 여부는 확정하지 않았으며 시스템 설정에 적용하지 않았습니다.

## 보존·자동화 경계

기존 디자인과 이미지 파일은 유지하고 원본 앱은 `.preview`에 보관했습니다. 개인 인증 파일·Codex 모델·MCP 설정·Notion 원문을 변경하지 않았습니다. 서버 실행, 계정 초대 발송, DB 생성, 상시 동기화, 예약 작업, 배포는 수행하지 않았습니다. UI 초대 링크는 사용자가 복사하는 방식입니다.

## S01 랜딩 확장

브랜드 랜딩은 `features/landing`의 LandingPage·IntroSequence·HeroSection·FeatureStory·FinalCTA로 나눴습니다. 내용·시간은 `content.ts`, 화면 밖/탭 비활성 모션 제어는 `motion.ts`, 스타일은 `styles/landing.css`에서 관리합니다. 새 의존성·애니메이션 라이브러리·외부 API·오디오 자동 재생은 추가하지 않았습니다.

공개 랜딩은 세션 조회와 독립적으로 먼저 표시합니다. 시작 CTA만 `/start`에서 인증·취향 상태를 확인하므로 인트로와 모션이 사용자 이동을 가로막지 않습니다. 추가 저장값은 현재 탭에서 인트로를 보았다는 선택적 표시 `tunit-brand-intro-v1`뿐이며 기존 계정·취향·인증 키는 유지합니다.

공통 스크롤 모션은 MutationObserver에서 늦게 마운트된 장면도 등록하도록 보완했습니다. 스크롤/크기 변경 때만 RAF로 CSS 변수를 갱신하고 정리 시 observer·이벤트·예약 프레임을 해제합니다. 장기 타이머·상시 동기화·서버 작업은 없습니다.
