## S01 랜딩

`/landing`은 서비스 소개용 독립 랜딩이고, `/home`은 로그인·취향 입력 후 사용하는 개인 화면입니다. 루트 진입은 랜딩을 엽니다. 공통 상단은 `+ MENU`와 로그인/내 취향을 제공하며, 하단 필름 릴은 랜딩의 네 챕터 또는 로그인 후 네 주요 화면을 표시합니다.

| 구역  | 연출·동작                                                                            | 소스                                 |
| ----- | ------------------------------------------------------------------------------------ | ------------------------------------ |
| S01-A | 전체 콘텐츠 영역의 약 1.8초 타이틀 인트로·건너뛰기·바로 시작하기, 탭 내 재진입 생략  | `features/landing/IntroSequence.tsx` |
| S01-B | 초대형 이탤릭 Tunit 워드마크·짧은 카피·작은 헤드셋/물감 썸네일                       | `features/landing/HeroSection.tsx`   |
| S01-C | 취향 분석 → Music Twin → 음악 발견 → 친구 1:1 비교; 목업·스크롤 등장·절제된 패럴랙스 | `features/landing/FeatureStory.tsx`  |
| S01-D | 취향·음악 노드 연결 모션, 지금 시작하기                                              | `features/landing/FinalCTA.tsx`      |

모든 시작 CTA는 프론트 `/start`에서 상태를 확인해 미로그인→`/login`, 취향 미완료→`/onboarding/intro`, 완료→`/home`으로 이동합니다. 인트로 자동 완료는 라우팅을 강제하지 않습니다. 로그인한 사용자도 랜딩을 둘러볼 수 있습니다.

인트로는 **헤더·하단 릴을 제외한 전체 콘텐츠 영역**에서 재생합니다. 인트로 안의 시작 CTA와 상단 시작·로그인을 바로 조작할 수 있고, 배경 콘텐츠는 전환 전까지 입력 대상에서 제외합니다. 건너뛰기 버튼을 키보드로 누르면 Hero CTA로 초점을 옮깁니다. OS 동작 줄이기를 켜면 인트로를 기다리지 않고 바로 콘텐츠를 보여줍니다. 새 인트로는 `tunit-brand-intro-v2` 표시를 사용하며 이전 표시와 계정 데이터를 유지합니다. 스크롤은 기본 브라우저 동작을 사용하며 섹션 이동이 Router hash를 덮어쓰지 않습니다.

반복 모션은 IntersectionObserver로 화면 밖에서 멈추고, 백그라운드 탭에서도 멈춥니다. 모바일에서는 떠다니기·회전·패럴랙스와 음파 수를 줄이고, 저속 화면 갱신·동작 줄이기에서는 정적으로 표시합니다. 목업은 “화면 미리보기”로 구분하고 실제 추천 수·사용자·매칭 점수를 만들어내지 않습니다.

콘텐츠와 장면 순서는 `features/landing/content.ts`, 공통 디자인은 `styles/editorial.css`, 랜딩 스타일은 `styles/landing.css`에 모았습니다. 메뉴는 Escape·Tab 초점 순환·닫기 후 초점 복귀를 지원하며, 하단 챕터를 누르면 인트로를 마치고 해당 장면으로 이동합니다. 이전 랜딩 소스는 `.preview/Landing.before-animated-landing.tsx`에 보존했습니다.
