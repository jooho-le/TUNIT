# 전체 프론트 단일 HTML 디자인 보드

## 요청

전체 페이지를 예시처럼 한 장에 펼친 HTML로 만들고, `frontend/design/` 안에 저장해 Figma에서 세부 디자인을 수정할 수 있게 한다.

## 변경 내용

- 기존 React 프론트에서 정적 마크업을 추출해 S01~S27과 주요 상태를 포함한 45개 장면을 단일 `showcase.html`에 배치했다.
- 랜딩은 인트로·Hero·4개 소개·최종 CTA로 펼치고 메뉴, 로그인·가입, 취향 입력·결과, 홈, 마이페이지, 탐색·비교, 초대, 관심·연결, P1/P2 화면을 흐름별로 묶었다.
- 데스크톱 화면 너비 1440px, 보드 너비 7600px를 사용하며 화면 ID·경로·상태·크기를 표시했다.
- 스크린샷·iframe 없이 실제 텍스트·SVG·CSS를 사용했다. 기존 세 가지 색상과 DESIGN3 방향을 유지했다.
- 이미지와 공개 폰트·라이선스를 포함해 서버·로그인 없이 파일 하나로 볼 수 있게 했다.
- 전체 맞춤, 확대·축소, 흐름 이동, 화면 확대와 Figma용 원본 HTML 저장 도구를 추가했다.
- 내보내기용 예시는 격리된 메모리 저장소에서 생성한다. 서비스 코드·실제 계정·Notion 문서·Codex 설정은 변경하지 않았다.
- 실제 앱을 다시 추출하는 수동 생성 명령과 Figma File 탭 반입 안내를 작성했다. 상시 서버·자동 동기화는 추가하지 않았다.

## 검증 결과

- `node frontend/design/generate.mjs`: 내보내기 검사 통과. 45개 프레임과 S01~S27, 로딩 제외, CSS 구문, ID 중복, SVG 필터 참조, 이미지·폰트 포함, API·브라우저 저장소 실행 코드 부재를 확인했다.
- 내보내기 파일 TypeScript 별도 검사 통과.
- `npm test`: 기존 6개 파일, 51개 검사 통과.
- `npm run build`: TypeScript 및 Vite 빌드 통과.
- 실제 Chrome에서 `file://`로 보드를 열어 45개 상태 표기, 전체 맞춤 배치와 폰트 표시를 확인했다.
- 개발·프리뷰·백엔드 서버는 시작하거나 재시작하지 않았다. Git 커밋·푸시·브랜치 변경은 하지 않았다.

## 미검증·한계

- 실제 Figma 파일 업로드·변환은 진행하지 않았다. 글꼴·SVG 효과·자동 레이아웃은 플러그인 결과에 따라 확인이 필요하다.
- 전체 45개 장면을 픽셀 단위로 실측하거나 Figma용 저장 버튼의 다운로드 결과를 확인하지 않았다.
- P2는 현재 프론트의 안내 화면이며 채팅·피드 기능을 새로 구현한 결과가 아니다.
- Figma 편집은 React 코드와 자동 동기화되지 않는다.
- 전체 한글 폰트를 포함해 단일 HTML은 약 20MB다.

## 외부 요청 처리

초기 폰트 최적화 방식은 HTML 문자 집합을 Google Fonts의 `text` 쿼리에 전달하려 했으나 자동 승인 검토에서 프로젝트 문구의 외부 전달 가능성을 이유로 실행 전에 차단했다. 해당 방식을 제거하고, 프로젝트 내용을 읽거나 전송하지 않는 고정 공개 폰트·라이선스 다운로드로 완료했다.
