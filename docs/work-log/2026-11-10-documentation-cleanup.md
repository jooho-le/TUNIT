# Markdown 문서 구조와 현재 상태 정리

- 날짜: 2026-11-10
- 요청: 기존 Markdown 문서를 찾기 쉽고 일관되게 정리.
- 범위: 문서·경로·링크만 변경. 앱·설정·기능·디자인 자산·Notion 원문은 변경하지 않음.

## 변경 내용

- 루트 README를 프로젝트 소개·필수 명령·문서 링크 중심으로 줄였다.
- `docs/README.md`를 문서 진입점으로 만들고 현재 구현 상태와 각 문서의 역할을 구분했다.
- 설치·실행·로컬 테스트 계정·저장소·환경변수는 `docs/development.md`로 모았다.
- 흩어져 있던 Notion 원문 링크와 P0~P2 범위를 `docs/requirements.md`로 모았다. 문서의 과거 “진행중” 상태를 현재 상태처럼 표현하지 않는다.
- API 경로의 생략 표기를 풀고, 실제 HTTP 어댑터가 사용하는 요청과 계약에만 있는 조회 경로를 구분했다.
- 화면·아키텍처·상태·DB·백엔드·배포 문서에 탐색 링크와 구현/미구현 구분을 정리했다.
- 랜딩 인트로가 오른쪽 Hero 영역의 짧은 모션이며 전체 화면 전환은 미구현임을 명시했다.
- 현재 디자인 기준은 루트 `DESIGN.md`에 정리하고, 브랜드 참고 원본은 아래 경로로 내용 변경 없이 옮겼다.
- 검증 기록을 마지막 앱 검사·테스트 코드·T01~T24 대응·한계로 재구성했다. 일시적인 초기 구현 메모는 이 기록 아래로 이관했다.
- 기존 초기 작업 기록은 변경하지 않고 새 기록을 추가했다.

## 검증

- Markdown 21개 문서의 내부 링크·앵커 144개 검사 통과.
- 디자인 참고 원본 3개의 SHA-256과 기존 Git 원문 일치 확인.
- 이미지 생성·수정 프롬프트 2개와 초기 작업 기록 원문 보존 확인.
- 변경 파일이 Markdown으로만 구성된 것을 확인. Markdown 형식 검사·`git diff --check` 통과.
- 앱 코드 변경이 없어 `npm test`·`npm run build`는 재실행하지 않음. 기존 44개 통과 결과는 과거 앱 검증 기록으로 유지.
- 서버 실행·Notion 수정·커밋·푸시는 수행하지 않음.

## 초기 구현 메모 이관

아래는 기존 테스트 문서에 있던 초기 구현 당시 해결 기록이다. 이번 문서 정리에서 다시 실행하거나 새로 수정한 사항이 아니다.

- jsdom의 `matchMedia` mock이 테스트 자동 복원 때 초기화되는 문제를 수정했습니다.
- 취향 삭제 뒤 온보딩을 열 때 기존 선택이 다시 보일 수 있어, 세션 프로필을 갱신한 다음 이동하도록 수정하고 빈 선택을 검증했습니다.
- 로그아웃 뒤 보호 경로의 재인증 흐름을 일관되게 정리했습니다.
- TypeScript의 API 래핑 타입 오류와 테스트용 Node 타입 누락을 수정했습니다.
- npm 레지스트리 DNS 제한으로 타입 패키지 설치가 한 번 실패했으며 허용된 네트워크 실행으로 설치를 완료했습니다.
- 이번에 추가한 Vitest 3 의존성의 보안 공지를 확인해 4.1.12로 교체했고, 기존 React·Vite 버전은 유지했습니다. [공식 보안 공지](https://github.com/vitest-dev/vitest/security/advisories/GHSA-qxg6-89mg-rqv8), [v4 호환 조건](https://v4.vitest.dev/guide/migration.html).
