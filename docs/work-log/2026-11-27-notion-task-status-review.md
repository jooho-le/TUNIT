# Notion 개발 완료·설계 속성 정리 — 2026-11-27

## 요청과 기준

사용자 요청에 따라 TUNIT 작업 트래커에서 개발이 완료된 항목은 상태를 완료로, 설계가 확정된 항목은 작업 구분을 설계 완료로 갱신한다. 실제 트래커 schema/선택지를 읽고 전체34개 페이지를 조회했다. 미완료18개 본문의 완료 기준·현재 결과·보류 정책을 읽고 기존 코드/명세/검증 기록과 대조했다.

완료 판단은 사용자가 요청한 **승인된 P0 개발 범위**의 구현·실제 Spring/PostgreSQL 통합 검증 기준이다. 회원탈퇴/개인정보 보존·P1 초대 철회·외부 공급자·운영 배포까지 완성됐다는 뜻이 아니다. 실제 브라우저/배포 추가 검증은 원문의 미완료 항목으로 보존하고 프론트 설계·오류 복구·환경/배포 작업에서 추적한다. 새 테스트 실행이나 임의 정책 확정은 하지 않았다.
