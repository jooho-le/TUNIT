# DESIGN3 기반 랜딩·프론트 디자인 개편

- 날짜: 2026-11-10
- 요청: 랜딩과 프론트를 `DESIGN3.md`의 Freshman 느낌으로 변경.
- 작업 브랜치: 사용자가 선택한 `frontend`. 시작 시 작업 파일 내용은 `dev`와 동일했고, 사용자가 추가한 미추적 `DESIGN3.md`는 원문 그대로 보존했다.
- 범위: 화면·스타일·공통 내비게이션·관련 테스트·문서. 서버·API·인증·데이터 규칙·백엔드·배포 설정은 변경하지 않음.

## 변경 내용

- 큰 제품 이미지 중심 Hero를 초대형 이탤릭 `Tunit.` 워드마크와 짧은 소개·괄호형 문구 중심으로 재구성했다.
- 노랑 `#FFF21A`, 차콜 `#171717`, 보라 `#A66BFF`를 유지했다. 노란 헤드셋과 보라 물감은 작은 썸네일에 보존한다.
- 인트로를 헤더·하단 릴을 제외한 콘텐츠 전체의 약 1.8초 타이틀 시퀀스로 바꿨다. 즉시 시작·건너뛰기·초점 복귀를 제공한다.
- 새 인트로는 `tunit-brand-intro-v2`로 한 번 표시하며, 이전 v1 표시와 계정/취향 저장값은 삭제하지 않는다.
- 상단 `+ MENU`에 전체 화면 목록을 연결하고 Escape 닫기·Tab 초점 순환·배경 입력 차단·이전 스크롤 복구를 구현했다.
- 하단에 필름 릴 형태 내비게이션을 고정했다. 랜딩은 네 챕터, 취향 완료 후 앱은 Home·Discover·Music·My Taste로 이동한다.
- 챕터를 누르면 진행 중인 인트로를 마치고 해당 섹션으로 스크롤하며 Router hash를 덮어쓰지 않는다.
- 가입·온보딩·Home·취향·추천·음악·초대·요청·연결 화면의 둥근 카드·버튼·입력을 각진 형태, 얇은 선, 평면적인 색상으로 맞췄다.
- 음악·취향 미리보기를 평면적인 레코드·아카이브 표현으로 정리하고 기능 흐름·공개/권한·빈 상태는 유지했다.
- 현재 디자인 기준·화면 지도·저장 키·문서 안내·검증 기록을 새 구현에 맞췄다.

## 글꼴과 모션

디스플레이는 공개 대체 폰트 Cormorant Garamond 300 이탤릭과 시스템 serif fallback을 사용한다. 유료 Editorial New를 설치하거나 원본의 빨간 색상을 적용하지 않았다. 기존 DM Sans·Noto Sans KR 본문을 유지한다. 외부 글꼴을 받을 수 없는 환경에서는 시스템 대체 글꼴로 표시된다.

반복 모션은 viewport 밖과 백그라운드에서 멈추며, 동작 줄이기 설정을 인트로 도중 켜도 타이틀 시퀀스를 종료한다. 키보드·기본 스크롤 동작과 입력 접근성을 유지한다.

## 검증 한계와 작업 경계

실제 브라우저·모바일 viewport·애니메이션 프레임과 외부 글꼴 다운로드는 확인하지 못했다. 실행 중인 5173 포트는 다른 프로젝트의 서버여서 사용하거나 재시작하지 않았다. TUNIT 서버를 새로 켜지 않았으며 DOM 테스트를 실제 시각 검증으로 표시하지 않는다.

커밋·푸시·병합·Notion 수정·서버 실행·배포는 수행하지 않았다. `main`·`dev`와 사용자의 다른 프로젝트는 변경하지 않았다.
